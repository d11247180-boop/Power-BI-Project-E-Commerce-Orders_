# Power-BI-Project-E-Commerce-Orders_

∗ Designed and built an interactive Power BI Sales Dashboard to track sales performance, target achievement, and
manager-wise contribution using dynamic visuals and KPIs.
∗ Cleaned and transformed raw sales data using Power Query, improving data quality through type correction,
handling missing values, and calculated columns.
∗ Developed key DAX measures such as Total Sales, Achievement percentage,and Sales Difference to enable accurate
performance insights and decision-making.
∗ Created a structured data model (star schema) integrating fact and dimension tables, improving data relationships
and enabling smooth filtering and interactivity across the report
